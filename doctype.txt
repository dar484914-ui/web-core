========================================================================
             ВИТЯГ: ТИПИ ТА ВЕРСІЇ DOCTYPE В HTML
========================================================================

1. ЩО ТАКЕ <!DOCTYPE>?
------------------------------------------------------------------------
Декларація <!DOCTYPE> (Document Type Declaration) — це обов'язкова перша 
строка HTML-документа. Вона вказує веб-браузеру, за якими стандартами 
та версією мови HTML/XHTML інтерпретувати та відображати веб-сторінку.

2. HTML5 (Сучасний стандарт)
------------------------------------------------------------------------
У версії HTML5 декларація була значно спрощена. Вона не чутлива до 
регістру та використовується в усіх сучасних веб-сайтах.

Синтаксис:
  <!DOCTYPE html>

3. HTML 4.01 (Класичний стандарт)
------------------------------------------------------------------------
У версії HTML 4.01 декларація посилалася на DTD (Document Type Definition), 
оскільки вона базувалася на мові SGML.

а) HTML 4.01 Strict (Суворий):
   Забороняє використання застарілих тегів (наприклад, <font>, <center>) 
   та фреймів.
   Синтаксис:
   <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd">

б) HTML 4.01 Transitional (Перехідний):
   Дозволяє використовувати застарілі теги та атрибути для сумісності зі 
   старими браузерами.
   Синтаксис:
   <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">

в) HTML 4.01 Frameset (Для фреймів):
   Використовується для сторінок, що містять фрейми (<frameset>).
   Синтаксис:
   <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Frameset//EN" "http://www.w3.org/TR/html4/frameset.dtd">

4. XHTML 1.0 (Строгий розширений HTML на основі XML)
------------------------------------------------------------------------
Вимагав суворого дотримання XML-синтаксису (усі теги закриті, елементи в 
нижньому регістрі тощо).

а) XHTML 1.0 Strict:
   <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">

б) XHTML 1.0 Transitional:
   <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">

в) XHTML 1.0 Frameset:
   <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Frameset//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-frameset.dtd">

5. XHTML 1.1
------------------------------------------------------------------------
Повністю модульна версія XHTML без підтримки застарілих елементів.

Синтаксис:
  <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.1//EN" "http://www.w3.org/TR/xhtml11/DTD/xhtml11.dtd">

========================================================================
ПІДСУМОК:
Зараз стандартною і загальноприйнятою є декларація <!DOCTYPE html>, яка 
підтримується всіма сучасними браузерами та мобільними пристроями.
